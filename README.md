# douyin-video-skill

把抖音视频的内容做成可复用的 agent skill。

## Skills

### viral-topic-picking
根据抖音@人类最强编导《给我两秒就好》（[视频](https://www.douyin.com/video/7690907639698132081)）的**完整字幕**整理而成，用来做爆款选题：脑科学四问，以及怎么造选题、怎么找选题。全文字幕在 `skills/viral-topic-picking/references/transcript.md`。

## Install

```
npx skills add liush2yuxjtu/douyin-video-skill --skill viral-topic-picking -g -y
```

## Trigger

“帮我想个选题”“这个选题能火吗”“从这个热点找选题”。
