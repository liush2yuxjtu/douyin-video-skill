# Viral Topic Picking（爆款选题）

选题决定一条视频的流量上限。选题的使命是抢注意力：让用户的大脑优先处理你的信息，拿到完播和停留。

## 核心规则：用户刷到视频时，大脑先做四个判断

1. **和我有关吗？（自我参照、用户认领）** 用一个难以量化的好特质去锚定人群，比如成熟、专业、聪明、有想法、有认知，因为人们通常觉得自己在这些方面高于平均水平。光连接身份还不够，还要连接欲望、困境和对方正在面对的问题。
   - 差：为什么年轻人越活越累（太大太空）
   - 好：为什么越懂事的人回家后越不想说话（用户会马上在自己身上找证据）
2. **我在乎吗？（兴趣强度）** 大脑优先处理奖励、损失、危险和欲望。要写用户正在承受的结果，不要只讲一个重要的话题。
   - 差：睡眠很重要
   - 好：为什么明明睡了 8 小时醒来还是很累
   - 连接的人数决定上限，兴趣强度决定停留。
3. **和我想的一样吗？（预期违背）** 答案和用户的预测一致，他就不必看下去。要打断他原来的判断，逼他问“为什么”。例子：为什么越努力的人收入反而越低。真正的选题是用户不知道的、理解错的、没想清楚的，或者想过但说不明白的东西。
4. **我能马上看懂吗？（合意难度）** 太简单会无聊，太难会被放弃，元素太多或太难都会让大脑不处理。要唾手可得：花一点但不多的时间和脑力，落在认知甜蜜点上。

## 怎么造选题（人群够大，兴趣强度也够大）

- **沿一个需求往下挖**：问题越具体，越能用具体的场景、痛点和渴望唤醒用户真实的生活记忆。
- **从不同现象提炼相同本质**：员工扛了部门大部分工作却一直没升职，全职妈妈用心照顾家十年却被当成理所当然。这两件事的共同点是“我的付出为什么被当成理所当然”。从具体身份上升到一群人，激活更大范围的共同情感记忆。

## 怎么找选题（从素材出发）

素材来自热点、评论区、个人经验、读书、电影等。热点事件由**角色、行为、事件**三类元素构成：

1. **从角色切入**：按你的账号定位选一个角色视角，再上升到一个群体，找共同的情感记忆。
2. **从行为切入**：找原因，或找结果，或总结做法，写成“当我用什么方式去做什么事”。
3. **从事件切入**：讲影响和反思，延伸到男女关系、AI、投资、金融、社会阶层等领域。

## Steps

1. 先问清楚或推断账号定位、目标人群，以及手上的素材。
2. 用上面的“找”和“造”方法产出 5 到 10 个候选选题，每个都写成一句标题或开头。
3. 每个候选按四问打分（每项 0 到 2 分），并写一句理由。
4. 输出排名前 3 的选题，每个配一句开头钩子，示例格式：`给我两秒，你是不是 X，但是 Y`，用认领加预期违背的结构。
5. 指出最弱的一问，以及具体怎么改。

## Fallback

- 没有素材时，就从账号人群当下最痛的一个具体场景往下挖。
- 人群太窄时，用“不同现象，相同本质”往上提。
- 太抽象时，换成用户正在承受的具体结果。

## Example

输入：职场号，素材是“同事抢功”。
输出：「为什么最能干的那个人，总是最后一个被看见」。认领：能干的人；在乎：付出被吞的损失；违背：能干却不被看见；合意难度：一句话就能懂。
